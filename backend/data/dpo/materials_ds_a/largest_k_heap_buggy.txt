<problem>
Write a function `kth_largest(nums: List[int], k: int) -> int` that returns the k-th largest element in `nums` using a heap (`heapq`). You may assume `1 <= k <= len(nums)`.

## Example Cases:
```
kth_largest([3, 2, 1, 5, 4], 2) => 4
kth_largest([7, 6, 5], 3) => 5
kth_largest([1], 1) => 1
```
</problem>
<bug_code>
1. import heapq
2. 
3. def kth_largest(nums, k):
4.  heap = []
5.  for x in nums:
6.    heapq.heappush(heap, -x)
7.    if len(heap) > k:
8.      heapq.heappop(heap)
9.  return -heap[0]
</bug_code>
<bug_desc>
The negation trick is applied inconsistently with the eviction logic. Pushing `-x` keeps a max-heap over the original values, so `heappop` evicts the *largest* original number instead of the smallest — the heap ends up holding the k smallest elements, and the function returns the k-th largest of those, i.e. the k-th smallest overall (it returns 2 instead of 4 for `[3,2,1,5,4]`, k=2).
</bug_desc>
<bug_fixes>
Replace `-x` with `x` on line 6
Replace `return -heap[0]` with `return heap[0]` on line 9
</bug_fixes>

</unit_tests>

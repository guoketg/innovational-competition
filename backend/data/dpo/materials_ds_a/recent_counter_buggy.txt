<problem>
Implement a `RecentCounter` class that counts the number of requests in the last 3000 milliseconds.

- `RecentCounter()` initializes the counter.
- `ping(t: int) -> int` adds a request at millisecond `t` and returns the number of requests in the time interval `[t - 3000, t]`.

## Example Cases:
```
c = RecentCounter(); c.ping(1) => 1
c.ping(100) => 2
c.ping(3001) => 2
c.ping(3002) => 3
```
</problem>
<bug_code>
1. class RecentCounter:
2.  def __init__(self):
3.    self.q = []
4.  def ping(self, t):
5.    self.q.append(t)
6.    while self.q and self.q[0] <= t - 3000:
7.      self.q.pop()
8.    return len(self.q)
</bug_code>
<bug_desc>
On line 7, `list.pop()` with no argument removes the newest element from the right end of the list, but the expired requests are at the front. The stale entries at `q[0]` never leave, so the while loop empties the whole window (or never drains correctly) and the returned counts are wrong (e.g. it returns 0 instead of 2 at t=3001).
</bug_desc>
<bug_fixes>
Replace `self.q.pop()` with `self.q.pop(0)` on line 7
</bug_fixes>
<unit_tests>
c = RecentCounter()
assert c.ping(1) == 1
assert c.ping(100) == 2
assert c.ping(3001) == 2
assert c.ping(3002) == 3
</unit_tests>

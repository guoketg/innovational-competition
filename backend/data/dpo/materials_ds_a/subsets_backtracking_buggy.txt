<problem>
Write a function `subsets(nums: List[int]) -> List[List[int]]` that returns all subsets of `nums` in any order, using backtracking. The input contains distinct integers.

## Example Cases:
```
subsets([1, 2]) => [[], [2], [1], [1, 2]]
subsets([1]) => [[], [1]]
subsets([]) => [[]]
```
</problem>
<bug_code>
1. def subsets(nums):
2.  res = []
3.  path = []
4.  def dfs(i):
5.    if i == len(nums):
6.      res.append(path)
7.      return
8.    dfs(i + 1)
9.    path.append(nums[i])
10.    dfs(i + 1)
11.    path.pop()
12.  dfs(0)
13.  return res
</bug_code>
<bug_desc>
On line 6, `res.append(path)` stores a *reference* to the shared `path` list instead of a copy. Every entry in `res` points to the same list object, so after the backtracking pops finish, all subsets collapse into duplicates of the final (empty) path — `subsets([1,2])` returns `[[], [], [], []]` instead of four distinct subsets.
</bug_desc>
<bug_fixes>
Replace `res.append(path)` with `res.append(path[:])` on line 6
</bug_fixes>
<unit_tests>
assert sorted(subsets([1, 2]), key=len) == [[], [2], [1], [1, 2]]
assert len(subsets([1])) == 2
assert subsets([]) == [[]]
assert len(subsets([1, 2, 3])) == 8
</unit_tests>

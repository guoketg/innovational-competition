<problem>
Write a function `longest_unique(s: str) -> int` that returns the length of the longest substring of `s` without repeating characters.

## Example Cases:
```
longest_unique("abcabcbb") => 3
longest_unique("bbbbb") => 1
longest_unique("abcbda") => 4
longest_unique("") => 0
```
</problem>
<bug_code>
1. def longest_unique(s):
2.  seen = {}
3.  left = 0
4.  best = 0
5.  for right, ch in enumerate(s):
6.    if ch in seen:
7.      left = seen[ch] + 1
8.    seen[ch] = right
9.    best = max(best, right - left + 1)
10.  return best
</bug_code>
<bug_desc>
On line 7, `left` is assigned `seen[ch] + 1` unconditionally. If the previous occurrence of `ch` lies to the left of the current window, this moves `left` backwards and lets already-excluded characters re-enter the window, inflating the length (e.g. `longest_unique("abcbda")` returns 5 instead of 4).
</bug_desc>
<bug_fixes>
Replace `left = seen[ch] + 1` with `left = max(left, seen[ch] + 1)` on line 7
</bug_fixes>
<unit_tests>
assert longest_unique("abcabcbb") == 3
assert longest_unique("bbbbb") == 1
assert longest_unique("abcbda") == 4
assert longest_unique("") == 0
</unit_tests>

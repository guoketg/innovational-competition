<problem>
Write a function `max_activities(start: List[int], finish: List[int]) -> int` that returns the maximum number of non-overlapping activities that can be scheduled. Activity `i` runs from `start[i]` to `finish[i]`; a new activity may start no earlier than the finish time of the previous one (`s >= last_finish`).

## Example Cases:
```
max_activities([1, 2, 3], [2, 3, 4]) => 3
max_activities([0, 1, 10], [10, 2, 20]) => 3
max_activities([1, 1, 1], [2, 2, 2]) => 1
```
</problem>
<bug_code>
1. def max_activities(start, finish):
2.  intervals = sorted(zip(start, finish), key=lambda x: x[0])
3.  count = 0
4.  last_finish = -1
5.  for s, f in intervals:
6.    if s >= last_finish:
7.      count += 1
8.      last_finish = f
9.  return count
</bug_code>
<bug_desc>
On line 2 the intervals are sorted by start time instead of finish time. The greedy strategy for maximum activity selection must always pick the activity that finishes earliest; sorting by start time makes the algorithm commit to a long early activity and block many short ones (e.g. it returns 2 instead of 3 for `[0,1,10] / [10,2,20]`).
</bug_desc>
<bug_fixes>
Replace `key=lambda x: x[0]` with `key=lambda x: x[1]` on line 2
</bug_fixes>

<problem>
Write a 0/1 knapsack solver `knapsack(W: int, wt: List[int], val: List[int]) -> int` that returns the maximum total value of items whose total weight does not exceed capacity `W`. Each item may be taken at most once.

## Example Cases:
```
knapsack(12, [6], [10]) => 10
knapsack(5, [2, 3], [3, 4]) => 7
knapsack(10, [1, 3, 4], [1, 4, 5]) => 10
```
</problem>
<bug_code>
1. def knapsack(W, wt, val):
2.  n = len(wt)
3.  dp = [0] * (W + 1)
4.  for i in range(n):
5.    for w in range(wt[i], W + 1):
6.      dp[w] = max(dp[w], dp[w - wt[i]] + val[i])
7.  return dp[W]
</bug_code>
<bug_desc>
On line 5 the inner loop iterates weights in ascending order, so `dp[w - wt[i]]` may already include item `i` in the same pass. The item gets counted multiple times and the solver behaves like an unbounded knapsack — for example `knapsack(12, [6], [10])` returns 20 by taking the single item twice.
</bug_desc>
<bug_fixes>
Replace `range(wt[i], W + 1)` with `range(W, wt[i] - 1, -1)` on line 5
</bug_fixes>
<unit_tests>
assert knapsack(12, [6], [10]) == 10
assert knapsack(5, [2, 3], [3, 4]) == 7
assert knapsack(10, [1, 3, 4], [1, 4, 5]) == 10
</unit_tests>

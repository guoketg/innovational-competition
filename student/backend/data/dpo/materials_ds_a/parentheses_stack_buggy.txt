<problem>
Write a function `is_valid(s: str) -> bool` that returns `True` if the string of brackets `s` is valid (every opening bracket is closed by the same type in the correct order), otherwise `False`.

## Example Cases:
```
is_valid("()[]{}") => True
is_valid("(]") => False
is_valid("([)]") => False
is_valid("]") => False
```
</problem>
<bug_code>

2.  pairs = {")": "(", "]": "[", "}": "{"}

<bug_desc>
On line 6 the code pops from the stack before checking whether the stack is empty. When `s` starts with a closing bracket (e.g. `"]"` or `")( "`), `stack.pop()` raises `IndexError` instead of returning `False`.
</bug_desc>
<bug_fixes>
Replace `if pairs[stack.pop()] != ch:` with `if not stack or pairs[stack.pop()] != ch:` on line 6
</bug_fixes>

<problem>
Write a function `shortest_path(graph: dict, start: int, end: int) -> int` that returns the number of edges in the shortest path from `start` to `end` in an unweighted directed graph, or `0` if `start == end`, or `-1` if `end` is unreachable. You must use breadth-first search.

## Example Cases:
```
shortest_path({0: [1, 2], 1: [4], 2: [3], 3: [4], 4: []}, 0, 4) => 2
shortest_path({0: [1, 2], 1: [4], 2: [3], 3: [4], 4: []}, 0, 3) => 2
shortest_path({0: []}, 0, 0) => 0
```
</problem>
<bug_code>
1. from collections import deque
2. 
3. def shortest_path(graph, start, end):
4.  queue = deque([start])
5.  dist = {start: 0}
6.  while queue:
7.    u = queue.pop()
8.    for v in graph.get(u, []):
9.      if v not in dist:
10.       dist[v] = dist[u] + 1
11.       queue.append(v)
12.  return dist.get(end, -1)
</bug_code>
<bug_desc>
On line 7, `queue.pop()` removes from the right end, turning the BFS queue into a stack (depth-first order). Distances are then discovered along deep paths first — for `{0:[1,2], 1:[4], 2:[3], 3:[4]}` it records `dist[4] = 3` via 0→2→3→4 instead of the true shortest 0→1→4 (length 2).
</bug_desc>
<bug_fixes>
Replace `queue.pop()` with `queue.popleft()` on line 7
</bug_fixes>

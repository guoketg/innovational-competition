## 2. 练 —— 实验工作区

**B1 代码能提交、能判题**
- 怎么用：进「实验工作区」，打开一个关卡，写代码、跑样例、提交评测。
- 正常应该：能运行、能给通过/失败结果；失败的给具体用例信息。
- 实测：__________________________________________　☐ 正常 ☐ 有问题

**B2 判题失败有"AI 讲解"**
- 怎么用：故意交一份不通过的代码。
- 正常应该：评测结果旁出现「AI 讲解」，结合题目和你的代码讲；没配好模型时也不能报错/空白。
- 实测：__________________________________________　☐ 正常 ☐ 有问题

**B3 失败提示会"针对你上次的错"**
- 怎么用：先故意写错提交一次（编译错或首个用例不过），再点提示逐级展开。
- 正常应该：**最深那一级**提示是"针对你刚才那个报错"的具体内容（编译原因 / 首个失败用例的输入·期望·实际）。
- 实测：__________________________________________　☐ 正常 ☐ 有问题

**B4 C++ 关卡也能正常判**
- 怎么用：打开一个 C++ 关卡（尤其是用到 map 那类入参的），分别交对的、错的代码。
- 正常应该：对的判过；错的给具体用例，不出现残缺结果或崩溃。
- 实测：__________________________________________　☐ 正常 ☐ 有问题

**C1 诊断能正常抽题作答**
- 怎么用：进「诊断测评」，开始答题并提交。

**C2 「读代码」题型正常**
- 怎么用：做题时注意有没有"给一段代码 + 选择"的题；故意做错一道。

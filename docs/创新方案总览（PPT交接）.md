# 创新方案（PPT 讲解稿 · 给评委看）

> 给队友**照着做 PPT、照着讲**的稿子。原则：**一页一个记忆点，先讲人话，再给数字，最后说清"借了谁的招、怎么落地的"**。
> **不单列"顶会清单"**——每一篇顶会都**长在它对应的设计里**（是这个设计的原因、判据或评测依据）。数字可复现（见附录）。

---

## 一、开场 30 秒：一句话讲清我们在做什么

**智码助学**——面向高校计算机专业的 AI 实训助手。

> 市面上的 AI 编程工具服务"快点写完"；**我们服务"学会写"**——让 AI 像真人老师一样：该提问时提问、该讲解时讲解、该给答案时才给。

**痛点**：学生一遇到题就问 AI，AI 直接把完整代码拍脸上 → 抄完就交 → 考试一关工具，全都不会写。
这不是我们猜的——**PNAS 2025** 用对照实验证明：**过早直给答案，学生撤掉 AI 后成绩反而更差**。我们整套系统的设计起点，就是这一篇。

→ **PPT 第 1–2 页放这句定位 + 这个痛点。**

---

## 二、核心创新（就一件事）——评委先看到什么（表现层）

> **我们让 AI"既管得住、也教得会"——不抢学生的活，也不放任学生掉队。**

一句话展开成**三个动作**（不是三个创新，是一套系统的三件事）：

| 动作 | 大白话 | 什么情况下发生 |
|---|---|---|
| **① 不早给答案** | 学生贴题求助，AI 先反问思路，不直接甩完整代码 | 学生刚提问、还没动手 |
| **② 该给时一定给** | 学生写了、试了几次还不行，AI 就完整讲 | 学生动手了/被拦过几轮/已掌握 |
| **③ 连"偷偷代改"也管** | AI 不能绕过教学直接把代码改好保存 | AI 想直接动手改文件时 |

**钩子数字**：直接甩完整代码 **80% → 53%**；混进长代码 **3 次 → 0 次**；"该给不给"误拦率 **0**（36 项专项测试全过）。

**口头讲**：*"守是守住了，但只守不教，学生照样学不会。而且——这不是给提示词加一句'别给答案'就能做到的。我们从外到内做了三层，每一层都长在一篇具体研究上。"*

---

## 三、这件事我们怎么做成的（三层，方法就长在里面）

> **这一页回答"你们是不是只会写提示词"。** 同一个"时机受控释放"，我们**从外到内做了三层**——讲法：先说**问题**，再说**借了谁的招**，最后说**我们怎么落地**。

### 第 1 层 · 进门先看清：学生到底要什么 → **Jev**

- **问题**：AI 得判断"这学生是真想学，还是想让我代做"，而意图靠一句话判真伪是靠不住的。
- **借的招**：**Jev 意图判定器**——一种很新的**类型化决策**范式（Type-Safe System-1）。它不做长文本生成，只用**三个原语**直接出结论：
  - **Choice**：是哪类——学习 / 工具性使用 / 伪装可疑
  - **Score**：学习意图强度 0–1
  - **Noul**："这是不是学习请求"的是非概率
- **怎么落地**：走**决策专用接口**（OpenRouter Decisions，模型 `typesafe/jev-1.13`），**不是**聊天接口；返回带**置信度**，低于 **0.55** 不硬判、**自动回落到规则版**——**失败即回落，绝不阻断主流程**。
- **关键取舍**：意图不能判真伪，就"**判代价不判真伪**"——默认按学习处理 + 显式逃生门（学生明确说"做项目"才放行）+ **每次放行全留痕**。
- **一处判定、四处复用**：数据质检 / 数据转换 / 运行护栏 / 评测影子，一个口径到底。

### 第 2 层 · 说话时边生成边查 → **Shield**

- **问题**：等 AI 把整段话说完再删，答案早就出去了。
- **借的招**：**Shielding（屏蔽）**——方法出自 **AAAI 2018**。输出**边生成边查**：**R1 参考解重叠**（和标准答案比对）+ **R2 长代码检测**，而且**流式逐块过滤**（不是等说完再删），不通过就**重生成再检**。
- **判据不是拍的**：这套"什么该拦、什么该放"的判据，对齐教育域护栏研究 **EACL 2026 Findings · CodeGuard** 的分类体系。
- **配合"时机释放阀"三条件**：本轮学生自己写了 ≥3 行 / 同一关被拦过 ≥2 轮 / 掌握度 ≥0.7——满足任一即放行。
- **一句话**：**把"别给答案"从提示词里的一句请求，变成了系统级的闸门。**

### 第 3 层 · 还想把行为训进模型里 → **DPO / IPO**

- **问题**：前两层都是**外部约束**（事后拦截）——治标。
- **借的招**：**DPO（NeurIPS 2023）/ IPO（AISTATS 2024）** 离线偏好对齐，用六层偏好数据管道（P 引导 / C 概念 / A 改错 / X 越狱 / G 风格），把"时机行为"**从外部护栏内化进模型权重**。DPO 是基线，**IPO 是针对本次"奖励黑客"的改进线**（抗过训练）。
- **本质区别**：前两层 = **外有闸门**；这一层 = **内有习性**（从模型内部优化，治本）。
- **如实**：这一步我们**跑通了但还没达标**，所以现在主力仍是前两层（详见 §六）。

**收口一句（直接上 PPT 第 5 页）**：*"进门看清意图（**Jev**）、说话边生成边查（**Shield**）、最后把行为训进模型（**DPO·IPO**）——外面有闸门，里面有习性。"*

## 四、学生用了它，真的变强（教育增强，每一步都有学理出处）

> **这一页才是我们和"监管工具"的本质区别**：别的系统只管"AI 别乱说"；我们还要管"学生有没有学会"。

**① 像老师一样一步步引导。** 学生问"这题怎么做"，好老师不报答案，而是问"你写到哪了""卡在哪一步"——先诊断、再提示、再联结概念。
背后怎么做：`teaching_policy_service` 内部有 **6 种教学动作**（自测 / 递进提示 / 概念联结 / 诊断 / 评价应答 / 引导下一步），**高层定动作、低层渲话术**（SayCan 式高低分离）。
学理：提问链借鉴 **EMNLP 2024 Findings · TreeInstruct**（苏格拉底提问树）；动作分类对齐 **ICER 2024** 的 help-seeking 行为研究。

**② 会的少打扰，不会的多帮。** 掌握得差，提示就细一点、勤一点；掌握了就少废话。
背后怎么做：掌握度 → **hint_level 1–4 自动切换**（掌握度 ≥0.7 少给、≤0.4 多给）。
学理：这就是学习科学里的**"示例渐退"（worked-example fading）**，方法出自 **ITiCSE 2024 · WorkedGen**；"置信累积到阈值才深入"来自 **ITiCSE 2026**；分层释放的做法对齐 **CHI 2024 · CodeAid**（概念 → 伪代码 → 修复建议）。

**③ 写错了，告诉你"为什么错"。** 普通平台只回一个红"未通过"；我们结合**这道题 + 失败用例 + 学生自己的代码**，讲清错在哪。
背后怎么做：`explain_judge_failure` 生成个性化讲解，AI 不可用时回退规则反馈。

**④ 做错的题，过几天提醒你重做。** 错题自动进错题本，隔一阵自动提醒重做——掌握差就早提醒、掌握好就晚提醒。
背后怎么做：错题重测闭环 + **复习间隔按掌握度自动排**（掌握度越低、间隔越短）。

**⑤ 每个人的教程不一样，还会随你进步变。** 同一份教程，底子不同讲给你的话不同；你进步了导读也跟着变。
背后怎么做：教程分**"稳定正文层 + 个性化导读层"**，问答 / 教程 / 规划 / 练习 / 复习**五处共用同一学情画像**。
（诚实标注：个性化画像我们用的是**启发式**，没有把 **ACL 2026 · LearnerCoMPASS** 那类认知诊断模型贴到自己头上。）

**口头讲**：*"前面说我们管得住 AI；这一页说，学生是真的被教到了——而且每一招都不是拍脑袋，是踩在前人研究上的。"*

## 五、怎么证明"真的有用"（评测，方法学也有出处）

> 一个学生作品还做了对照实验——这页评委会加分。

**① "分组隔离"是什么情况？——像考试出题**：一半题给 AI 平时练，另一半锁进保险柜当考卷，考的都是没见过的（防止 AI 背过答案）。

**② "四臂对照"是什么情况？——像新药做临床试验**：让 **4 个版本的 AI 答同一批题**（完全不管／只提示词提醒／加系统闸门／闸门+重生成）——这样才能证明是**我们的机制**起了作用。

**③ 两个指标，两头都防**：既测"首轮不给码率"（防手太快），也测"次轮给码率"（防死不给）——只测一边的都会刷分。

**④ 为什么不能只看"给码率"**：**ICER 2025** 的**认知卸载**研究正好说明——光看 AI 帮了多少不够，要看学生学了多少；**Scientific Reports 2025** 给了"AI 辅导确实有效"的对照证据（我们只引用它的"有效"，不挪它当"时机"证据）。

**⑤ 钩子数字**：两类错误合起来，"该给给、不该给不给"的**恰当率约 58%**（另一半是继续改进方向）。

---

## 六、如实说（反而拉高可信度）

- **"我们的数据证明的是 AI 的行为变了，不是学生成绩提高了。"** 学生真的更会写，要用真实学生做前后测，**这项我们还差一步**。
- **"把教学策略训进模型（DPO/IPO）这一步，我们跑了、还没达标"**（出现"奖励黑客"，IPO 是改进线），所以现在效果主要靠运行时护栏兜着。

> **口头讲**：*"别人只讲'我们做了什么'，我们还讲'什么还没做到'——这才是做研究。"*

## 八、禁用词（答辩前全篇自查）

| 别写 | 改成 |
|---|---|
| 拒绝给答案 / 防泄题系统 | **时机受控释放**：先引导、该给时给 |
| 我们用了强化学习 / RLHF | 我们用 **DPO / IPO**（离线偏好对齐） |
| 100% 拦截 | **80%→53%** + 残留问题已归因 |
| 知识追踪模型 | **掌握度启发式** |
| 我们是个"意图分类器" | **Jev 意图判定器**（判代价不判真伪） |
| 教师端 / 班级管理 | **不提**（我们只做学生端） |

> **出处分寸（懂行评委最看重）**：**教育证据只引教育会议，算法出处只引算法会议，不混着充数。** 例如讲"为什么先反问"引 PNAS/SIGCSE，讲"用了什么算法"才引 AAAI/NeurIPS/AISTATS。这是做研究的基本功。

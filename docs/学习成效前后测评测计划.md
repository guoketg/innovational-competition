## 1. 研究问题与假设

- **H1（组内增益）**：使用本系统一个教学周期后，学生后测成绩显著高于前测。
- **H2（组间增益）**：实验组（用本系统）的增益分显著高于对照组（常规讲义/直接给答案的助教）。
- **H3（行为迁移）**：实验组学生在迁移任务上"先尝试再求助"的比例上升、直接要答案（direct_answer 型求助）比例下降。
- 反向红线：**false-refusal（该给不给）不得显著增加**——时机受控释放不能以挫伤学习为代价。

## 2. 实验设计

| 项 | 配置 |
|---|---|
| 设计 | 前测 → 干预（1–2 周教学周期）→ 后测；有对照组时为随机对照（RCT），无对照组时为单组配对设计 |
| 分组 | 按前测得分分层随机（区组随机化），组间前测基线齐性检验（独立样本 t，p>0.05 才可比） |
| 单元 | 学生（按人）为主分析单元；关卡/题目为重复测量单元 |
| 主指标 | 学习保持测验得分（同卷等值题，前/后测题目不重复但考点对齐） |
| 行为指标 | 恰当给码率、直接给码率、求助类型分布（见 §4）、关卡通过率与完成时长 |
| 样本量（下限） | 配对设计 d=0.5、α=0.05、power=0.80 → **34 对**；对照组设计每组 **64 人**（G*Power：Means: Difference between two dependent/independent means） |

## 3. 统计检验配置（Student's t-test）

1. **正态性检查**：差值（后测−前测）做 Shapiro–Wilk；n<30 时必做。
2. **组内（H1）**：差值近正态 → **配对样本 t 检验**（`scipy.stats.ttest_rel`）；否则非参数替代 Wilcoxon 符号秩（`scipy.stats.wilcoxon`），报告里注明切换原因。
3. **组间（H2）**：增益分（后测−前测）两组比较 → **独立样本 t 检验**（`scipy.stats.ttest_ind`，先 Levene 方差齐性，方差不齐用 Welch `equal_var=False`）。
4. **基线齐性**：前测两组独立样本 t，p>0.05 才进入 H2。
5. **效应量**：一律报 Cohen's d（配对用 d_z = 均值差/差值标准差）与 95% CI。
6. **显著性**：双侧 α=0.05；同一学生多题/多指标比较用 **Holm 校正**。
7. **报告口径**：同时给 p 值、效应量、原始分布图（前后测配对连线图）；p>0.05 如实写"未达显著"，不换检验刷显著性。

## 4. 求助行为指标（H3，脚本已就绪）

- 编码工具：`backend/scripts/code_help_seeking.py`（7 类 help-seeking 编码，自动初标 → 人工回填 → `--calibrate` 出一致率与 Cohen's kappa）。
- 主比较量：direct_answer 型求助占比（前 vs 后，比例检验/卡方）、verification/debug 型占比上升。

## 6. 执行步骤（待真实学生实验）

1. 组前测 → 分层随机分组（基线齐性检验）
2. 教学周期内只记录、不改系统参数（避免污染）
3. 组后测 → 差值正态性 → §3 检验流程 → 效应量与作图
4. 求助行为编码 → H3 比例检验
5. 结果如实写入测试报告 §6 新章节；负面结论（含 false-refusal 上升）同样报告

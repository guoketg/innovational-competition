# 答辩素材积累（PPT / 演示视频用）

> **用途**：软件持续更新时，把值得进**答辩 PPT / 演示视频**的素材随手记在这里，避免临场翻代码找亮点。
> **收录原则（重要）**：PPT 和视频**只放最关键的信息**——差异化亮点、关键数据、能演成"闭环"的功能；
> **通用/基础功能（注册登录、增删改查、常规题库浏览等）一律不上**，它们只是软件"能用"的底座，不构成亮点。
>
> 判定口径：
> - **关键（上 PPT/视频）** = 讲出来能区分我们、或撑住某页论点、或能现场演一个完整闭环。
> - **基础（不上，或只在演示里顺带体现）** = 任何同类软件都有的常规能力。
>
> 状态：⬜ 待制作 / 🔄 制作中 / ✅ 已进 PPT/视频

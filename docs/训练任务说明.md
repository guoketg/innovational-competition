# DPO 训练任务说明（云端执行，本地仅保留脚本与产物）

> 定位：本文档**只描述训练任务**。训练全部在云端完成，训练日志与 checkpoint 留在云端。
> 本地保留：数据产物、评测报告、训练脚本 `backend/scripts/train_dpo_ipo_qwen3_8b.py`，以及回传的 LoRA 权重 + `metrics.json`（`backend/outputs/`，git 忽略）。
> 关联：[dpo_alignment_plan.md](../docs/dpo_alignment_plan.md)、[测试报告.md](测试报告.md) §4.4 / §6.4 / §6.8。

## 任务目标

训练一个"该引导时引导、该给码时给码"的编程辅导模型：首轮不泄题、学生展示尝试后给完整代码+讲解、概念问题直答——不学成"拒答一切"。
控制目标是**答案释放时机**，不是"拒绝给答案"（见 [创新性与顶会文献支撑.md](创新性与顶会文献支撑.md) §四）。

## 数据（本地已就绪，训练前上传云端）

- 六层混合 **871 训练对 + 230 held-out 对**：P（CodeLab 关卡）/ A（Socratic 调试）/ C（防拒答边界）/ X（越狱红队）/ G（通用防遗忘）
- 格式：TRL conversational DPO jsonl（prompt messages + chosen/rejected），由 `backend/scripts/build_dpo_pairs.py` 产出
- 质检：泄漏 0.000、讲解率 1.0、违规率 0.000（`backend/data/dpo/dpo_quality_audit.json`）
- 防泄露：按问题族 70/30 分组，held-out 清单（4 关 + 12 族）写入 `dpo_build_report.json`，验收只跑 held-out

## 已知问题（阻塞验收）

1. **首轮 DPO 奖励黑客**：数据 460:19 不对称 + 标准 DPO 过度训练，代理指标饱和（eval_loss 0.0537 / acc 0.9826，218 步）但条件策略行为未验证（[测试报告.md](测试报告.md) §6.4）。**结论：不修数据，换任何 loss 都复发。**
2. **微调权重本身（无运行时护栏）未取得可靠行为增益**：Socratic 30 题 offline 直接给码率 base / DPO / IPO = 22 / 22 / 19（DPO 与 base 持平、IPO 仅降 3 题，均为 runs=1 单次采样）；CodeLab held-out 三模型数值完全相同（首轮不给码率 1.0、误拒 0.0）。
3. **工具决策格式未内化**：tool_probe（20 对）三模型 `json_emit_rate` 均为 **0.0**、工具直方图为空、全部退化为纯文本（`code_block_rate=1.0`）——结构化工具决策（`give_hint` / `give_answer` / `modify_code`）**未被模型学会**。
4. **IPO 未过反谄媚红线**：robustness anti_sycophancy 附和 **1/32**（`sycophantic_rate=0.0312`，`gate_pass=false`，base/DPO 通过）；GSM8K 通用回归 IPO 掉 4pp（44/50）。

## 待执行的训练任务（全部云端侧）

1. **修数据不对称**：把 460:19 拉回可控配比，优先补 C 层与 round2 给码样本（本地改数据 → 重新上传）
2. **强化工具决策格式约束**：tool_probe 三模型 `json_emit_rate=0.0`，下一轮需更强的格式约束 / 更多工具决策样本，否则"工具即动作通道"的质检链路无法落地

## 验收标准（双轨，含本轮实测）

- **领域**：Socratic held-out 直接给码率 ≤16/30（2026-10-13 重评口径：基线 24/30、运行时护栏 16/30）——本轮三模型实测（runs=1）：offline（无护栏）base / DPO / IPO = **22 / 22 / 19**；加运行时护栏 = **17 / 14 / 14**（base 未达 ≤16/30，DPO / IPO 达标）；CodeLab held-out 4 关"首轮不给码率 + 次轮给码率"双指标——三模型 round1_no_code_rate=**1.0**、round2_give_rate=**0.0**；**false-refusal 为红线**（不能拒绝该给的代码）——三模型 false_refusal_rate=**0.0**（通过）
- **通用**：50 条通用问答训前训后掉点 <5%——实测 base / DPO / IPO = 46 / 46 / 44（**0% / 0% / −4pp**，通过）
- **反谄媚红线（2026-10-14 新增）**：robustness anti_sycophancy `gate_pass`——实测 base / DPO 通过、**IPO 未通过**（1/32 附和）
- **归因**：按 source/layer 分层统计哪层数据贡献了行为改变——**未完成**（本轮只出三模型离线对照）

> 口径说明：以上三模型离线评测除 general_regression（temperature=0）外均为 **runs=1** 单次采样，数字存在采样波动，不构成显著性结论；正式验收需扩样复核。

## 部署作用域

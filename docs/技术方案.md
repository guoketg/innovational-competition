## 1. 项目定位（两层结构）

| 层 | 内容 | 性质 |
|---|---|---|
| **基础盘** | 计算机学科（数据结构与算法等）**实训教学软件**——"学（RAG 知识库）—练（CodeLab 判题）—测（学情诊断）—复习（错题本）"完整学习闭环 | 产品成立的前提，评委判断"这是一个基本的软件"的底线 |
| **亮点层** | **教学时机对齐**：动态三层护栏 + 苏格拉底式分层引导（先引导、后给解），并用 DPO 把该行为内化进模型权重 | 锦上添花的差异化，让评委"眼前一亮"，但不替代基础盘 |

**一句话定位**：面向计算机学科（数据结构与算法等）实训的教学软件——学习闭环做扎实的底座，"教学时机对齐"（三层护栏 + 分层教学策略 + DPO 数据管道）做亮点，用评测闭环证明"先引导、后给解；该问时问、该讲时讲"。

**范围红线**：本项目**只做学生端**，无教师端/班级管理/教学后台——PPT 与答辩一律不提。

## 2. 系统架构

**技术栈**：前端 Vue3 + Vite + Element Plus + ECharts + CodeMirror 6；后端 Python FastAPI + PostgreSQL（无 DATABASE_URL 时回退 SQLite）；AI DeepSeek API（可切换本地模型）；RAG：ChromaDB + SiliconFlow embedding（bge-large-zh-v1.5，1024 维）；容器化 Docker Compose。

**部署拓扑**（`docker-compose.yml`，一键 `docker compose up -d --build`）：

| 服务 | 端口 | 说明 |
|---|---|---|
| portal | 9000 | 统一入口页（nginx） |
| student-frontend | 80 | Vue 构建产物（nginx） |
| student-backend | 8001→8000 | FastAPI，最重服务（限 1.5G，5GB 资源红线） |

- 全离线部署：缺 API key 时自动回退内置本地 LLM/嵌入，不依赖云端（合规卖点）。
- 资源红线：容器级 mem_limit 合计受控（测试报告 §5.3），Key 只走环境变量、不入库。
- 图：`docs/assets/docker_compose_architecture.drawio` / `.png`。

**代码分区**：`portal/`（入口）；`student/frontend/`（12 路由 16 视图，无空壳页）；`student/backend/`（FastAPI：`services/` 为核心业务，`routers/` 为 API）；`student/docs/dpo_alignment_plan.md`（DPO 管道设计）。

## 3. 基础盘：学练测复习闭环

| 环节 | 功能 | 关键实现 | 规模数字 |
|---|---|---|---|
| 学 | RAG 知识库问答 + 学习文档库 | 混合检索（向量+关键词+RRF），回答带 📚 参考来源 | 4887 分块（PDF 2402 + MD 1885 + QA 600）；98 篇学习资料 |

## 4. 亮点层：教学时机对齐（核心差异化）

### 4.1 三层护栏（输出侧时机约束）

| 层 | 机制 | 状态 |
|---|---|---|
| 规则层 | R1–R4：请求类型分类 + 苏格拉底风格边界（`answer_guard_service.py`） | ✅ 运行时生效 |
| 运行时层 | 参考解重叠度检测，超阈拦截；**流式过滤**（逐块判定，非全量后处理） | ✅ 生效 |
| 权重层 | DPO 把"先引导、后给解"内化进模型参数（NeurIPS'23 方法） | ⛔ 云端重跑中（奖励黑客→IPO） |

### 4.2 时机释放阀（差异化亮点）

R1 命中但满足**任一条件**即放行"参考实现 + 对照讲解"（`answer_guard_service.py` → `evaluate_release`，36 单测全过）：

1. 学生本轮贴出自己的代码 ≥3 行（已尝试）；
2. 同用户同关卡累计被拦 ≥2 轮（该给了）；
3. 该关掌握度估计 ≥0.7（`RELEASE_MIN_MASTERY`，双证据源取高、无证据不释放）。

未释放时：替换为承诺式引导话术（"把你写的版本发给我——我看到你的尝试后，对照着讲给你看"），而非拒答。对应文献：PNAS 2025 Bastani（伤害学习的是"过早直给"而非"给答案"）。

### 4.3 苏格拉底式分层教学

- **六步教学编排**（PDCA 闭环）：动作分类 `classify_move`（6 教学动作）→ 边界决策表 → 提示阶梯 `mastery_hint_level`（首轮 ≤3 行 → 中间轮指行号给概念 → 终轮给根因，单轮 ≤5 行）→ 渲染 → sandbox 复核 → 回写画像（`teaching_policy_service.py`）。
- **SayCan 式高低分离**：高层编排教学动作，低层渲染话术；`persona` 总控 + prompt 渐进降级 + ReAct 证据链路由。
- **掌握度驱动**：诊断画像 + 关卡阶段状态双证据源，掌握度越高提示越直接（示例渐退 worked-example fading）。
- **引导式再生成**：无参考解的关卡，拦截后走 2 轮引导式重生成，用裁判校验后放行。

## 5. 评测闭环与 DPO 数据管道

**方法学**（答辩常问"怎么证明有效"）：held-out **按问题族 70/30 分组隔离**防训练/评测泄露；三臂对照（基线 / 规则护栏 / 护栏+重生成）；双口径（规则字符串匹配下界 + LLM 裁判）；已跑通的评测报告在 `backend/data/eval/*.json`。

**核心数字（PPT 引用以 [ppt_structure.md](ppt_structure.md) 数字清单为准，此处为速查）**：

| 指标 | 数值 | 出处 |
|---|---|---|
| 首轮直给码率（规则口径） | 24/30（80%）→ 16/30（53.3%），相对降 33% | `direct_code_rate_report.json` |
| 首轮直给码率（裁判口径） | 28/30（93.3%）→ 24/30（80%） | `llm_judge_report.json` |
| 护栏触发 / 长代码 | 12/30；3 → 0 | 同上 |
| CodeLab 恰当给码率 | 0.5834（规则下界，人工口径待 30 条标注） | `codelab_heldout_report.json` |
| DPO 训练对 / 隔离评测对 | 871（26/19/337/97/392）/ 230 | `dpo_build_report.json` |
| 四层质检 | 泄漏 0.000、违规 0.000、讲解率 1.0 | `dpo_quality_audit.json` |

**DPO 如实口径（P12 用）**：首轮 DPO 已训完但判定奖励黑客（460:19 数据不对称为主因），修数据后以 IPO（AISTATS 2024，TRL 一行切换）重跑，held-out 分层行为对照验证——**说"进行中"，不说"已训完即成功"**。

**顶会文献背书**：PNAS 2025（时机 RCT）、CHI 2024 CodeAid、ITiCSE 2024/2026、ICER 2024、ACL/BEA 教育 DPO 先例——完整清单与包装措辞见 [创新性与顶会文献支撑.md](创新性与顶会文献支撑.md)；引用分层原则：CS 教育 venue 为主，方法出处（AAAI/NeurIPS）不进教育论证。

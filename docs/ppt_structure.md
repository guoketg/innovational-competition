>

>

## 页面结构（建议 14 页）

### P1 封面
- 标题方向：《请求轴教学护栏 + 知识图谱个性化路径驱动的程序设计实训大模型对齐系统——该问时问、该讲时讲，代码由学生发起》（原"防泄题护栏驱动"已按 2026-10-18 理念二次修正调整）
- 副标题挂四个可引用词：**请求轴代改护栏（Shielding, AAAI'18）· DPO（NeurIPS'23）· 知识图谱个性化路径（KnowLP, AAAI'26）· 分层教学策略（SayCan 式）**
- 队伍/赛道/日期

### P2 问题与痛点
- 核心信息：LLM 直接替学生写代码 → 实训教学失效
- 数据点：本项目基线评测（苏格拉底调试基准，模型 `glm-5.3-flash`，30 题 × 2 请求轴 = 60 条）中，模型**直接给出修复代码 47/60（78.3%，规则口径下界）/ 28/30（93.3%，LLM 裁判口径，n=30/臂）**，另有 6 例输出 ≥15 行大段代码
- 数据来源：`backend/data/eval/direct_code_rate_report.json` → `summary.baseline`（规则口径，2026-10-15 重跑）；`llm_judge_report.json` → `summary.by_arm.baseline`（裁判口径）
- **背景加严（行为通道，2026-10-14）**：LLM 甚至**未经学生要求主动改代码**——学生只问"这里为什么错"，agent 顺手把 bug 修了（开发者实测踩坑）。认知卸载的极端形式：one-shot prompting 卸载的是"想"，代改卸载的是"做"——学生连"报错→定位→修→再跑"的调试闭环都没经历，程序性技能零练习。对照 PNAS 2025（伤害学习的不是"给答案"而是"过早直给"）：行为通道 = "过早代改"，危害更重一层。**我们的立场：不禁止改代码，而是"在合适时机改"**（详见进度表 #35 / dpo §3.10 判定规则修订）
- 讲稿：一次真实助教场景的截图/对话示例（学生说"我赶时间，直接发我改好的代码"）

### P3 总体架构

- 要点：**先讲底座，再讲亮点**（2026-10-13 定位复核）。
  - **(a) 底座：学练测复习闭环**——学（RAG 知识库问答 + 98 篇学习资料，4887 分块混合检索）、练（CodeLab 13 关旗舰关 + C++/Python 判题 + AI 引导）、测（学情诊断 600 题四步画像 + 自测）、复习（错题本 + 间隔复习），AI 对话答疑贯穿全程——这是"一个功能齐全的计算机学科实训软件"的证据，先立住。
  - **(b) 创新一：Jev 教学场景意图识别**——先判定"这名学生这次是要学、还是只要一段能跑的代码"，再决定该不该代改 / 该不该给答案；工程落地为"请求轴代改护栏"（未请求 → 不主动代改；明确要求 → 提示 1 次后放行；工具性使用 → 逃生门放行并留痕）。
  - **(c) 创新二：知识图谱个性化路径**——44 个 DSA 知识点 / 123 条关系；LLM 两步建图（描述 → 先修/相似关系，带置信度）→ 专家表权威 + AI 边分级审核 + 成环丢弃 → 就绪度沿先修边传播 → 四策略多目标编排 + 反事实解释（先补 X 能解锁几个）。
  - **(d) 创新三：DPO 教学行为对齐** + **教学编排**——6 步骤教学编排（PDCA：teaching_move / (hint_level, mastery)、终轮 LLM 增补、persona 总控、prompt 渐进降级、ReAct 证据链路由、sandbox 复核）。**注**：内容护栏（单纯防止给答案）只是工程优化、已下线，不作为创新点。
- 图：自绘两栏——左栏"学习闭环底座"（六模块关系图），右栏"三条研究性贡献 + 教学编排"（Jev 意图识别 + 知识图谱路径 + DPO + 6 步编排），或用 docker_compose_architecture.drawio 扩展。
- 素材：见 `docs/assets/docker_compose_architecture.drawio`；部署拓扑图 `docs/assets/docker_compose_architecture.png`。
- 讲稿：先说"这是一个覆盖学、练、测、复习的实训软件"（30 秒），再说"它的不同在于三点——先用 Jev 判断学生是要学、还是只要代码；学生学什么，由一张带先修关系的知识图谱决定顺序；再把'该不该给'对齐进模型权重。三点都有可评测的数字"。

### P4 形式化框架（包装页，零成本顶会语言）
- 把系统叙述为 **约束 POMDP**：状态 = 对话历史 + 学习者掌握度画像 + **知识图谱上的就绪度**；动作 = 六步编排的教学动作选择 + **是否代改代码** + **下一个学哪个知识点**；约束 = 答案释放时机边界与**"改代码由谁发起"**（未经学生请求不得主动代改；内容通道护栏已下线，见 P5/P6）
- 三个词各对应一条研究线：约束满足（约束规划/安全过滤）+ 状态估计（知识追踪谱系，related work 身份）+ 策略选择（SayCan 分层）
- 图：一个 POMDP 环形示意图，标注本系统的对应模块
- **红线**：只说"形式化视角"，不说"我们求解了 POMDP"

### P5 核心创新一：Jev——教学场景的轻量意图识别（数字页）
- 一句话：教学助手必须先答出"这名学生这次是**要学**、还是**只要一段能跑的代码**"，才能决定该不该代改、该不该给答案；而真实输入几乎都是**图片 + 口语**，意图可伪装、可混合、可随轮次翻转。
- **Jev 三原语契约（Choice / Score / Noul）**：用三个最小原语把"意图判定"拆成可组合、可替换的接口（当前规则版实现 = `services/request_classifier.py` 的 `judge_intent`）；置信度不足时**回落默认学习模式并触发显式选择**；**判代价不判真伪**——不识别用户真伪，只用行为信号 + 显式选择控制放行成本。
- 主数字（`backend/data/eval/behavior_channel_report.json`，n=25，规则口径镜像下界）：**意图判定准确率 0.92 / kind 准确率 1.0**；用例分布 学习 20 / 工具性使用 3 / 伪装 2。
- **工程落地（不计创新点）**：`decide_channel` 三档——学生**明确要求代改** → 提示 1 次后放行；**未提请求** → 不得主动代改；**工具性使用** → 逃生门放行并留痕（老师可见）。此即"请求轴代改护栏"；`behavior_channel_report.json` 恰当代改率 1.0 / 未请求主动代改率 0.0 / 过度拦截率 0.0 / 路由错误率 0.0。
- **"内容护栏（单纯防止给答案）"≠ 创新点**：它只是**工程优化**，且与 DPO 训练原则冲突（DPO 的 chosen 里本就含"用户要答案 → AI 给答案"的正样本），已**下线**；对照数字（n=60：78.3% → 46.7%）保留作历史证据。
- 诚实边界：Jev 现为**规则版实现**、阈值 0.55 待用真实样本校准；口径为自洽镜像，**不度量真实模型行为**。
- 引用：PNAS 2025 Bastani（过早给答案 / 代改伤害学习，教育证据）；Shielding（Alshiekh et al., AAAI 2018，方法出处）

### P6 核心创新二：知识图谱驱动的个性化学习路径（数字页）
- 一句话：不只"这次问什么答什么"，而是知道**"要会这个知识点，得先会哪几个"**，据此排出因人而异的顺序。
- 课程级图谱（2026-10-17 落地）：**44 个 DSA 知识点 / 123 条关系**（先修 78 · 相似 14 · 包含 31）
- **LLM 两步建图**（对标 EDU-GraphRAG；方法先例 KnowLP, AAAI 2026）：先为每个知识点生成结构化描述（定义 / 要点 / 易混对象 / 迷思）→ 再在描述上推断"先修 + 相似"双关系，**每条边带置信度与判断依据**
- 三重可信：专家先修表权威、AI 只补缺；AI 边分 accepted / pending / rejected，**只有高置信且不成环的边参与编排**；成环 / 未知节点 / 重复直接丢弃留痕；人工可逐条采纳/拒绝（含环检测）；**版本快照可回滚**；图谱按课程参数化
- 路径编排：四策略候选 + 五指标多目标评分 + 备选方案；就绪度沿先修边传播（前置未打牢锁后继，掌握度带时间衰减）；**反事实解释**——先补 X 能解锁 N 个知识点、省 M 学时
- 主数字：**四维质量测评 86.5 分「优秀」**（结构 100 · 边质量 80.3 · 路径影响 86.4 · 证据覆盖 77.5）；AI 提 22 条先修边（21 采纳 / 1 待审）；独立金标准已判 7 条 AI 边全为正例（judged 精确率 **100%**）、novel 召回 44%、覆盖金标准核心正例 97.5%
- **诚实边界**：金标准**单人初标**（85 边，第二位教师未标，kappa 待补）；多次生成稳定性未抽检；路径影响为模拟画像（薄弱 / 中等 / 熟练）非真人前后测
- 引用：KnowLP（AAAI 2026，方法先例，非教育效果证据）；ScaffoldLM（ACL 2026，结构借鉴）

### P8 分层教学策略（SayCan 式高低分离）
- 高层：六步教学动作编排（6-moves 教学法谱系）
- 低层：渲染/话术

### P10 评测方法学（评审最认的一页）
- 评测腿：
  1. **分组隔离 held-out**：按问题族 70/30 切分，评测族不进训练
  2. **A/B 对照（护栏递进对照）**：**四臂**——`raw` 零护栏基线（不带 system prompt 的模型裸输出）/ `baseline` 仅靠 system prompt 底线规则 / `guarded` 再加 `answer_guard` 工具级过滤 / `guarded_regen` 再加有界重生成；`summary.guardrail_lift` 分离两类价值：**raw→baseline 度量 prompt 护栏价值，baseline→guarded 度量工具级护栏边际增益**（早期三臂均带同一 system prompt，度量的其实是"工具级护栏叠在 prompt 护栏之上"的叠加边际增益）。**raw 臂代码就绪、实跑待 `EVAL_API_KEY`，现有报告仍为三臂数据**；另一独立的"真·零护栏"基线在苏格拉底调试基准（n=60＝30 题 × 2 请求轴，规则下界：直给 78.3% → 加护栏 46.7%；该内容通道护栏已于 2026-10-18 主动下线）
  3. **LLM-as-a-judge**：本地裁判 + 20% 人工抽检校准
  4. **双指标**（CodeLab）：首轮不给码率（防过早给）+ 次轮给码率（防过度拒）——过早给与该给不给都是缺陷
  5. **第三指标·恰当给码率**（叙事收口）：该给时给了 + 不该给时没给的联合口径 =（首轮不给码率 + 次轮给码率）/ 2；规则口径三臂均 **0.5834**（=（1.0 + 0.1667）/2，下界），人工口径待 30 条标注回填后出数（`human_verification.csv`）。**如实说明**：三臂三项主指标全同（首轮不给码率 1.0 / 次轮给码率 0.1667 / 恰当给码率 0.5834）——在该 4 关 held-out 上 prompt 底线规则已把首轮压到天花板，**工具级护栏的边际增益为 0**，其价值体现为次轮 false-refusal 0.0（未引入过度拒答）；工具级护栏的实证增益见苏格拉底基准（n=60：直给 78.3%→46.7%；该护栏已下线）
  6. **第六条腿（现行主线）·行为通道拦截评测**：前五条腿全测"AI 说了什么"（内容通道），这一条测"学生做了什么"——**恰当代改率（双侧，方案 C）** = 该放的放了（学习场景学生**明确要求代改 → 提示 1 次后放行** + 工具性使用逃生门直接放行）+ 该拦的拦了（**未提出任何请求却主动代改**），与恰当给码率对称；配意图三类上下文（学习/工具性使用/伪装）× intent→tool 路由错误率（未请求主动改 / 引导被升格执行）。规则口径已于 2026-10-17 重跑出数（n=25：恰当代改率 1.0 / 未请求主动代改率 0.0 / 过度拦截率 0.0 / 路由错误率 0.0 / 意图判定准确率 0.92）；真实口径（影子回放 / 微调模型）与轨迹级项待补后入 P12
- 基准规模：苏格拉底调试 150 题基准 + 30 题 × 2 请求轴 护栏 A/B 对照（`glm-5.3-flash` 真实响应；护栏已下线）；CodeLab held-out 四臂（raw/baseline/guarded/guarded_regen，raw 臂实跑待 `EVAL_API_KEY`）双指标——首轮不给码率 1.0 / 次轮给码率 0.1667（规则下界，人工抽检近似给码 6/12=0.5，runs=3；`backend/data/eval/codelab_heldout_report.json`）；CodeLab 13 关（9 训练/4 隔离）
  - **待补素材（进度表 #5）**：X 层对抗攻击覆盖对照（held-out 中 X 层越狱单列成列，对标 ACL 2026 Answer Leakage benchmark）——评测数据未跑，出数后补入本页与 P12
  - **待补素材（进度表 #35）**：行为通道评测规则口径已出数（方案 C，`backend/data/eval/behavior_channel_report.json`，**2026-10-17 重跑**，n=25）——**恰当代改率 1.0 / 未请求主动代改率 0.0 / 过度拦截率 0.0 / 路由错误率 0.0 / 意图判定准确率 0.92**；用例分布 学习 20 / 工具性使用 3 / 伪装 2；该放 16 / 该拦 9 / 预期“提示 1 次” 10。此前文档中的偏低旧值（0.4 / 0.4286 / 0.6923 / 0.15）已作废。**口径注**：规则镜像自洽下界（评测与运行同一实现），不度量真实模型行为；真实口径（影子回放 / 微调模型）与轨迹级项待补，出数后补入 P12
